# Style lock

## Direction contract
- Thesis: an approachable, image-led guide to the Rick and Morty universe.
- First viewport: clear section title, concise introduction, and immediately browsable catalog entries.
- System: Material 3 navigation, warm dark surfaces, amber accents, system sans typography, and API character artwork.
- Risk: decorative science-fiction motifs could reduce readability; keep them restrained.

## Color contract
Playful dark palette: text #FAF0E5, background #120E09, surface #1E1914, primary #A6670A, on-primary #FFFFFF, accent #D98A20, border #2A2520.
Text-safe pairs: text/background 17.08:1, text/surface 15.49:1, accent/background 6.96:1, accent/surface 6.32:1, on-primary/primary 4.60:1. Borders are decorative.

## Typography and spacing
Platform sans, Material text roles; spacing 4, 8, 12, 16, 24, 32. Rounded surfaces with 16px radius. Native Material icons and controls.

## Assets and motion
Use existing app identity and API character images. Short Material transitions and progress indicators; respect platform reduced motion. No new illustration or photography is needed for the catalog.
