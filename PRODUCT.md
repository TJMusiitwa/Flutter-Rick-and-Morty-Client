## Platform

## Users

Fans of Rick and Morty exploring the show's characters, episodes, and locations; developers examining a Flutter application using a GraphQL API.

## Product Purpose

Provide a browsable client for canonical information from the Rick and Morty API and demonstrate a real-world Flutter and GraphQL integration.

## Capabilities and Constraints

The existing app browses paginated characters, episodes, and locations and shows their details. It uses the Rick and Morty GraphQL API. The user has not specified additional branding or platform constraints.

## Evidence on Hand

The API supplies the catalog and character images. See README.md for attribution and ownership information.

## Product Principles

- Make the catalog easy to browse and understand.
- Keep API information and attribution accurate.
- Keep the app useful as a Flutter and GraphQL showcase.
